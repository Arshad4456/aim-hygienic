# Step 2 File Map

## Frontend

- Routes: `frontend/app/portals`
- Legacy redirect: `frontend/app/dashboards/[[...slug]]/page.js`
- Features: `frontend/src/features`
- Live tracking: `frontend/src/features/live-tracking`
- App shell: `frontend/src/app-shell`
- Config: `frontend/src/config`
- Design system: `frontend/src/styles`

## Backend

- Config: `backend/src/config`
- Core system: `backend/src/core`
- ERP templates: `backend/src/core/erp-templates`
- Business module wrappers: `backend/src/modules`
- Central route registrar: `backend/src/routes/index.js`

## Mobile

- Config: `mobile/src/config`
- Feature modules: `mobile/src/features`
- Theme: `mobile/src/theme`
- App bootstrap: `mobile/src/app`
