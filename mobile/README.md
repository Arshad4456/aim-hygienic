# AIM ERP Mobile (Expo React Native)

Production-oriented Expo mobile client that mirrors web dashboard module structure from `frontend/app/dashboards/**` using auto-generated role menus and route registry.

## Environment

Set backend base URL (same Node backend used by website):

```bash
export EXPO_PUBLIC_API_BASE_URL="https://your-domain.com"
```

> Mobile API client auto-appends `/api` if needed.

## Run in Expo Go

```bash
npm install
node scripts/generate-role-routes.mjs
npm run start
```

## Build Android with EAS

```bash
eas build --profile preview --platform android
```

Production AAB:

```bash
eas build --profile production --platform android
```

## OTA updates (optional)

Publish OTA update:

```bash
eas update --branch production --message "mobile parity update"
```

## Architecture

- `src/api/client.js`: single backend client + bearer token + 401 logout.
- `src/auth/*`: secure session with `expo-secure-store`.
- `src/navigation/RoleMenu.generated.js`: role/module menu generated by scanning website dashboards.
- `src/navigation/RouteMap.generated.js`: generated route metadata + endpoint hints.
- `src/features/<role>/**/index.js`: generated parity skeleton screens for each web module route.
- `src/shared/dashboard/*`: mobile shared dashboard components (shell/module center/messages/settings/receipts concept).

## Upload policy

Mobile app uses backend presigned flow only:
1. `POST /uploads/presign`
2. `PUT` to returned signed URL
3. backend attach call

No R2 keys are stored in the app.
